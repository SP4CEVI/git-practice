# git-practice — консольный калькулятор

Учебный проект для практических работ по дисциплине
«Технологии разработки программного обеспечения».

## Возможности
Операции: `+`, `-`, `*`, `/`, `**` (степень), `%` (процент от числа).

## Запуск
    python3 main.py
    
## Тесты
    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements-dev.txt
    python -m pytest -v
    
## Структура
| Файл | Назначение |
|---|---|
| main.py | точка входа, меню |
| config.py | название и версия |
| operations.py | арифметические операции |
| validators.py | проверка ввода |
| utils.py | форматирование результата |
| history.py | история вычислений |
| tests/ | unit- и интеграционные тесты |

## Документация по коду
Генерируется автоматически при каждом обновлении `main`
и публикуется на GitHub Pages: https://sp4cevi.github.io/git-practice/
